## Quick Phase Summary

- **Phase 0** (Ignition — shadow mode, nothing acts): Build spine + one low-stakes triad.
- **Phase 1** (Calibration & first autonomy): Measure accuracy, graduate safe actions.
- **Phase 2** (Scale workforce): Add more lanes, heads, cluster-leads.
- **Phase 3** (Command layer): Chief Orchestrator + Auditor + gated tools (Stripe, etc.).
- **Phase 4** (Full org): Complete departments with tight Risk/People controls.

**Key Milestone:** First live autonomous action (after calibration).
